# CanyonRace ゲーム設計

会話で決めた方針を記録する。ホバー走行、衝突、体力、5秒待機、3機制限をC++試作へ実装。基礎操作とSteam視点リセットは実機確認済み。バーニア操作と景観は引き続き調整する。

## 合意した方向

- Windows PCからSteam Frameへ配信するPCVRゲーム。
- 浮遊感・慣性・峡谷を抜けるスピード感を優先する。
- 地表数mを滑走し、崖や段差で大きく浮き上がるホバー走行を基本にする。
- 慣性と横滑りを先読みする、習熟が楽しい操縦を目指す。
- 左スティック下で機首上げ、上で機首下げ。機体各部のバーニアで姿勢を制御し、LRボタンは翼の独立逆噴射。

## 耐久力と残機

- 機体は体力制。壁に接触すると弾かれ、ダメージを受ける。通常の接触では即座に破壊されない。
- 体力が尽きると機体が破壊される。
- 破壊後、リスポーンまで5秒待つ。
- 1レースに使える機体は3機まで。

「3機」は初期機体1機と予備2機、最大2回のリスポーンとして整理する。3機目の破壊でリタイア（DNF）とする解釈。別の意図があれば変更する。

## 試作への採用内容と暫定値

- 短い峡谷コースのタイムアタックで操縦感を調整する。
- 衝突ダメージは壁へ向かう速度成分を基準にし、かすり傷と正面衝突に差をつける（ユーザー了承済み）。
- 以下は試作の調整用初期値で、固定の合意事項ではない：体力100、衝突ダメージ最大75、損傷間隔0.4秒、復帰時のダメージ保護1.5秒。
- リスポーンは最後に通過したチェックポイント。体力全回復・停止状態で復帰する。ゲートは順番通過が必要で、復帰で進行を飛ばせない。
- 5秒の待機中もレース時間は進む。3機目の破壊で時間を止め、DNFにする。
- 操縦席視点。機体とカメラが上下・左右に一緒に傾く。カメラの揺れ調整UIは未実装。
- USGS峡谷の川沿い約4.29 km、19ゲートのRiver Run。基礎操縦の試験コース。
- 約4.26 km、14ゲートのSummit Drop。台地から川への約300 mの自然な降下を使う。
- 幅30 m・長さ80 m・高さ12 mの人工ランプ2基で離陸・着地を試す。
- 上下の姿勢指令は最大±85度、ピッチ速度上限100度/秒。左右は最大40度のバンク、ロール速度上限90度/秒。ニュートラルで徐々に水平復帰。
- 主推力は機首方向へ24 m/s²（ブースト時1.65倍）。慣性を保つため、速度方向は機首へ即座に揃えない。3次元速度の上限110 m/s（ブースト時1.2倍）。
- バンクで横向きの力を出して旋回し、低速では姿勢用バーニアが補助する。主推力以外の上昇用揚力は廃止。地表のホバー支持力は鉛直方向。
- 翼の逆噴射は片側18 m/s²。片側の旋回は最大45度/秒、左右同時は相殺。空気速度に依存せず、押し続けると後退もできる。
- 小さな白い噴射を機体各部に配置。粒子・動的照明・影・衝突を持たない単一メッシュセクションで表示する。
- 接触時はUnrealのSafeMoveで重なりを解消し、衝突後も残り時間の反発・接線方向の移動を処理する。低速の接触は滑り、高速の接触は従来の反発とダメージを適用。
- バーニア方式への変更に伴い自己ベストは `vernier-v1` として分離。以前のファイルは保持。
- コース別自己ベストと、自己ベスト走行の同じゲートとの差を表示。完走のみ保存し、DNFや自動操縦の検証は保存しない。

## 未確定
