# CanyonRace ゲーム設計

会話で決めた方針を記録する。ホバー走行、衝突、体力、5秒待機、3機制限をC++試作へ実装。基礎操作とSteam視点リセットは実機確認済み。追加の揚力操作、左右ブレーキ、景観は引き続き調整する。

## 合意した方向

- Windows PCからSteam Frameへ配信するPCVRゲーム。
- 浮遊感・慣性・峡谷を抜けるスピード感を優先する。
- 地表数mを滑走し、崖や段差で大きく浮き上がるホバー走行を基本にする。
- 慣性と横滑りを先読みする、習熟が楽しい操縦を目指す。
- 左スティック下で揚力による上昇、上で下降。LRボタンの独立エアブレーキでも旋回できる。

## 耐久力と残機

- 機体は体力制。壁に接触すると弾かれ、ダメージを受ける。通常の接触では即座に破壊されない。
- 体力が尽きると機体が破壊される。
- 破壊後、リスポーンまで5秒待つ。
- 1レースに使える機体は3機まで。

「3機」は初期機体1機と予備2機、最大2回のリスポーンとして整理する。3機目の破壊でリタイア（DNF）とする解釈。別の意図があれば変更する。

## 試作への採用内容と暫定値

- 短い峡谷コースのタイムアタックで操縦感を調整する。
- 衝突ダメージは壁へ向かう速度成分を基準にし、かすり傷と正面衝突に差をつける（ユーザー了承済み）。
- 以下は試作の調整用初期値で、固定の合意事項ではない：体力100、衝突ダメージ最大75、損傷間隔0.4秒、復帰時のダメージ保護1.5秒。
- リスポーンは最後に通過したチェックポイント。体力全回復・停止状態で復帰する。ゲートは順番通過が必要で、復帰で進行を飛ばせない。
- 5秒の待機中もレース時間は進む。3機目の破壊で時間を止め、DNFにする。
- 操縦席視点。機体のロールをカメラに強制しない。カメラの揺れ調整UIは未実装。
- USGS峡谷の川沿い約4.29 km、19ゲートのRiver Run。基礎操縦の試験コース。
- 約4.26 km、14ゲートのSummit Drop。台地から川への約300 mの自然な降下を使う。
- 幅30 m・長さ80 m・高さ12 mの人工ランプ2基で離陸・着地を試す。
- 前進速度の二乗に応じて揚力と左右ブレーキ旋回が強くなり、35 m/sで制御量が上限に達する。停止・後退では揚力なし。
- 引き切った際の追加揚力は最大18 m/s²、重力は9.8 m/s²。空中の入力ニュートラルでは重力に従う。調整用のアーケード飛行モデル。
- 片側ブレーキによる追加旋回は最大45度/秒。左右同時は差が消えて直進減速。
- コース別自己ベストと、自己ベスト走行の同じゲートとの差を表示。完走のみ保存し、DNFや自動操縦の検証は保存しない。

## 未確定

体力値・ダメージ曲線・揚力・ブレーキ旋回の最終調整、修理アイテム、周回数、対戦人数、武器。コース外と手動復帰は暫定で機体破壊と同じ扱い。
