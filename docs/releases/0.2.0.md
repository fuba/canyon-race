左右スティックの旋回を、機体を傾けて曲がるバンク方式へ変更しました。

- 最大40度のバンクに応じた横向きの力で、地上・空中ともに旋回。高速ほど旋回半径が大きくなります。
- スティックを戻すと徐々に水平へ復帰。コクピットと視点も機体のバンクに追従します。
- バンク中にスティックを引くと旋回が強まり、鉛直方向の揚力は少し減ります。
- 左右独立エアブレーキ、上昇・下降、Steam Frame入力、Steam視点リセットは継続。
- ログにバンク角、旋回角速度、バンクによる横加速度を追加。
- 挙動が変わったため自己ベストを新しく集計します。旧記録ファイルは保持します。

ルール8件、衝突・復帰・ジャンプ、左右バンクと実際の進路、水平復帰、左右ブレーキ、両コースの完走を自動検証します。VRでの乗り心地は引き続き調整中です。

ZIP全体を展開し `Play-VR.cmd`、高低差コースは `Play-Summit-VR.cmd` で起動してください。
ソースのcommitと検証項目は `build-info.json`、配布ZIPのSHA-256は `.sha256` ファイルで確認できます。
