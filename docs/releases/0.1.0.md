CanyonRaceの最初の公開試作版です。Windows PC + SteamVR / OpenXR、Steam FrameへのPC配信向け。

- 慣性のあるホバー走行、速度に応じた揚力での上昇・下降。
- 左右独立エアブレーキによる旋回と両側ブレーキ。
- Steam Frameのネイティブ入力、着座位置補正、Steam視点リセット追従。
- River Run（約4.29 km）とSummit Drop（約4.26 km、約300 m降下）。USGSの実地形を使用。
- 体力、衝突反発、5秒リスポーン、3機制限。
- コース別自己ベスト、ゲート通過時のタイム差、入力・姿勢・フレーム診断ログ。

ZIPを全展開し `Play-VR.cmd` を実行。高低差コースは `Play-Summit-VR.cmd`。
モニター用はそれぞれ `Desktop` の起動ファイルです。
詳しい操作と動作条件は同梱READMEを参照してください。

初版はDevelopmentビルドです。対戦・武器・オンライン機能はありません。
ソースのcommitと検証項目は `build-info.json`、配布ZIPのSHA-256は `.sha256` ファイルで確認できます。
