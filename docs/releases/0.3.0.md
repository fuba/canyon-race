機体各部のバーニアで姿勢と推力を制御する操作へ更新しました。

- 上下スティックで機首を最大±85度へ向けます。主推力は機首の方向へ作用し、垂直に近い上昇・下降ができます。
- 左右スティックのバンク旋回は継続。上下・左右ともニュートラルで徐々に水平へ戻り、コクピットと視点も機体に追従します。
- L/Rは翼の逆噴射。片側で減速と旋回、両側で直進方向に逆噴射。停止中にも効き、押し続けると後退します。
- 機体各部に控えめな白い噴射を追加。粒子・動的ライト・影を使わず、単一メッシュセクションで描画します。
- 地面との接触で座標だけ止まる問題を修正。重なりを解消し、衝突後も残りの移動量を処理します。旧処理で停止する4つの接触条件と比較し、修正版で継続移動を確認しました。
- ピッチ、推力、接触、要求移動距離・実移動距離のログを追加。走行記録は新しい操作体系として分離し、以前のファイルを保持します。

主推力または逆噴射で計時開始。詳細な操作は同梱READMEを参照してください。
ルール、上下姿勢と推力、逆噴射、バンク旋回、接触回復、衝突・復帰、両コース完走を自動検証します。VRでの乗り心地は引き続き調整中です。

ZIP全体を展開し `Play-VR.cmd`、高低差コースは `Play-Summit-VR.cmd` で起動してください。
