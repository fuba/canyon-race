# CanyonRace — 操作ガイド

ZIP全体を展開し、`Play-VR.cmd`（SteamVR）または `Play-Desktop.cmd`（モニター）で起動します。
高低差のあるコースは `Play-Summit-VR.cmd` / `Play-Summit-Desktop.cmd`。
Windows PCからSteam Frameへの配信を想定したPCVR版です。
SteamVRを起動し、OpenXRランタイムをSteamVRに設定してから実行してください。
初回にランタイム不足の表示が出た場合は、同梱の
`Engine/Extras/Redist/en-us/vc_redist.x64.exe` を実行します。

| 操作 | Steam Frame | キーボード | Xbox系 |
|---|---|---|---|
| 推力 | 右トリガー | W | RT |
| バンク旋回 | 左スティック左右 | A / D | 左スティック左右 |
| 機首上げ／機首下げ | 左スティック下／上 | ↓ / ↑ | 左スティック下／上 |
| 左／右逆噴射 | L / Rショルダーボタン | Q / E | LB / RB |
| 両側逆噴射 | 左トリガー、またはL+R | S、またはQ+E | LT、またはLB+RB |
| ブースト | A | 左Shift | A |
| レース再開始 | B | R | Start |
| 1機消費して復帰 | Y | Backspace | Y |
| 視点合わせ | 右スティック押し込み、またはX | F | 右スティック押し込み |
| 音切替／終了 | — | M / Esc | — |

Steam Frameは固有OpenXRプロファイルを使います。Touch互換機では片側逆噴射は左右グリップ、復帰は左Y、視点合わせは左Xです。
Steamボタンによる視点リセットにも追従します。着席し、正面を向いて視点を合わせてください。

地表から約3.5 mを自動ホバーします。左スティックを下へ引くと機首が上へ、上へ倒すと下へ向きます。最大±85度。
主推力は機首の向きへ作用するため、上向きで加速すると垂直に近い離陸ができます。姿勢だけを変えても速度の方向は即座には変わりません。
左右スティックで最大40度バンクして旋回。ニュートラルでは上下・バンクとも徐々に水平へ戻ります。
片側の逆噴射は、その翼の前から小さな白い炎を出し、減速しながら同じ側へ旋回します。左右同時なら旋回が相殺されます。
逆噴射は空気抵抗ではなく推力なので、停止したあとも押し続けると後退します。姿勢制御も速度に依存しません。
コクピットと視点は機体の上下・バンクに追従します。頭の動きとSteam視点リセットは引き続き使用できます。

主推力または逆噴射で計時開始。ゲートを順に通過してください。青い門がチェックポイント、最後の橙色がゴールです。
川沿いの **River Run** は約4.29 km / 19ゲート / 人工ジャンプ2基。
**Summit Drop** は約4.26 km / 14ゲート / 台地から川への約300 mの降下。自然地形のコースです。
飛びすぎるとゲートの上を通過してしまうので、出口を見越して下降・減速してください。

体力100、壁では反発しダメージ。破壊すると5秒待って最後のゲートへ復帰します。
1レース3機、3機目を失うとDNF。待ち時間も計時されます。

操縦席に速度、体力、残機、次ゲート、昇降速度、左右逆噴射量、自己ベストとゲート差を表示します。
SPLITがマイナスなら自己ベスト走行より先行。未完走やDNFは記録を更新しません。
記録は `%LOCALAPPDATA%/CanyonRace/Records/` にコース別保存されます。
今回の新しい挙動に対して初めて完走した時点から記録します。

診断ログは `CanyonRace/Saved/Telemetry/` に保存されます。入力・姿勢・フレーム時間・接触回数・要求移動距離と実移動距離を記録し、外部へ送信しません。
